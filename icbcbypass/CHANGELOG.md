# Changelog

## 1.1.0

- 适配工商银行 3.0.90，支持 3.0.80 ~ 3.0.90
- 修复 CALayer 动画拦截导致的界面卡顿：从永久拦截改为速率限制（突发检测）
- 信号量忙等循环添加 sched_yield() 降低 CPU 开销
- 解冻定时器改为永久运行，30s 后降频至 5s 间隔
- 新增 ICBC app 版本号日志记录

## 1.0.0

- 完全绕过工商银行 3.0.80 的越狱检测三层防御
- 对抗 SecureUtilityPlus 检测框架的文件/路径/环境变量检查
- 解除主线程持续冻结循环（RunLoop freeze）
- 拦截退出弹窗链路，防止强制退出
- 使用 fishhook + Logos 组合方案，绕过 MSHookFunction 限制
- 登录与正常使用均已验证通过

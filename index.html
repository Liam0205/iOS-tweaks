0x01 Tweaks

适用于 rootless 越狱 (Dopamine / palera1n) 的插件仓库。

可用插件

  • ABCBypass-农业银行反检测-rootless v1.0.1
    绕过中国农业银行的越狱环境检测，使其在越狱设备上正常运行。在农业银行 11.1.0 版本验证可用，适用于 rootless 越狱（Dopamine 等）。
  • BankcommBypass-交通银行反检测-rootless v0.2.1
    绕过交通银行的越狱环境检测，使其在越狱设备上正常运行。在交通银行 10.3.0 版本验证可用，适用于 rootless 越狱（Dopamine 等）。
  • BMWBypass-My BMW反检测-rootless v0.0.2
    绕过 My BMW（de.bmw.connected.mobile20.cn）的越狱检测弹窗，使其在越狱设备上正常运行。检测 SDK 为 IOSSecuritySuite，hook 其越狱/逆向检测入口。在 My BMW 6.8.2 版本验证可用，适用于 rootless 越狱（Dopamine 等）。
  • HSBCBypass-汇丰反检测-rootless v0.0.1
    绕过汇丰中国 / 汇丰香港的越狱环境检测，使其在越狱设备上正常运行。适用于 rootless 越狱（Dopamine 等）。
  • ICBCBypass-工商银行反检测-rootless v1.1.1
    绕过中国工商银行的越狱环境检测，使其在越狱设备上正常运行。在工商银行 3.0.90 版本验证可用（支持 3.0.80 ~ 3.0.90），适用于 rootless 越狱（Dopamine 等）。
  • LianJiaBypass-链家贝壳反检测-rootless v0.1.1
    绕过链家、贝壳找房 App 的越狱环境检测，使其在越狱设备上正常运行。在链家 9.86.91、贝壳找房 3.06.21 版本验证可用，适用于 rootless 越狱（Dopamine 等）。
  • MYBankBypass-网商银行反检测-rootless v1.2.1
    绕过网商银行的越狱环境检测，使其在越狱设备上正常运行。在网商银行 4.7.36 版本验证可用（支持 4.6.4 ~ 4.7.36），适用于 rootless 越狱（Dopamine 等）。
  • SimTouch v0.1.0
    Remote touch simulation and screenshot capture for jailbroken iOS
  • SSHTunnel v1.3.2
    SSH reverse tunnel manager. Establishes a reverse SSH tunnel from this device to a remote server, enabling remote access to the device. Supports autossh for automatic reconnection.
